Building Smart Learn: Adaptive AI Curriculum Engine with Vector RAG

Smart Learn is an AI-powered study companion and active recall platform designed to eliminate passive learning. Students and developers can upload slide PDFs, video or audio lecture recordings, or simply paste documentation links. The platform extracts and embeds the content into Supabase pgvector, orchestrates a Retrieval-Augmented Generation (RAG) pipeline, and unlocks 24/7 conversational tutoring, automatic active recall flashcard generation, and adaptive retention quizzes.

🌐 Live App: smart-learn-web.vercel.app 💻 GitHub Repository ⚖️ MIT License

The Problem: The Inefficiency of Passive Study

Traditional university and self-taught technical study routines rely on reading through 200-slide PDF decks, re-watching hour-long recorded lectures, and reviewing scattered highlights. Cognitive psychology consistently proves that passive re-reading has near-zero long-term retention according to the Ebbinghaus forgetting curve.

To truly master challenging domains—from distributed systems to systems biology—learners need three interlocking feedback loops:

  • Contextual Socratic Dialogue: The ability to interrogate specific paragraphs, request step-by-step breakdowns, and resolve ambiguities immediately without waiting for office hours.
  • Spaced Active Recall: Self-testing with flashcards where the brain must actively construct answers before flipping the card.
  • Objective Retention Verification: Timed multiple-choice quizzes with immediate diagnostic explanations for wrong answers.

1. Multimodal Ingestion Pipeline

Study materials rarely come in clean plaintext. Smart Learn handles three distinct ingestion vectors through specialized serverless API handlers:

  • PDF Extraction (/api/parse-file): Utilizes pdf-parse to extract text buffers while stripping redundant page headers, footers, and page numbers that pollute embeddings.
  • Media Parsing: Ingests recorded lectures, extracting audio streams for transcription and structured topic segmentation.
  • Direct Web Link Ingestion: Fetches external articles, Wikipedia pages, or documentation sites directly, bypassing manual copy-paste workflows.

2. Vector RAG Pipeline with Supabase & Prisma

Extracted documents are partitioned into semantic chunks using a sliding window with token overlap (typically 500 tokens with a 50-token overlap) to prevent losing conceptual context across boundaries.

Each chunk is converted into high-dimensional vector embeddings and stored in Supabase PostgreSQL enabled with the pgvector extension. When a user asks a question or triggers quiz generation, Smart Learn executes an exact cosine similarity query against the stored chunks: 

import { db } from "@/lib/db";

export async function getRelevantChunks(queryEmbedding: number[], documentId: string, limit = 5) {
  // Execute cosine similarity query using pgvector <=> operator
  const chunks = await db.$queryRaw`
    SELECT 
      id, 
      content, 
      1 - (embedding <=> ${queryEmbedding}::vector) AS similarity 
    FROM "DocumentChunk" 
    WHERE "documentId" = ${documentId}
    ORDER BY similarity DESC 
    LIMIT ${limit};
  `;
  
  return chunks;
}

3. Interactive Flashcards & Active Recall Engine

The /api/flashcards endpoint instructs the LLM to analyze the ingested knowledge chunks and isolate core concepts, definitions, formulas, and theorems.

  • Structured JSON Output: The model generates an array of { question, answer, difficulty, topic } objects, enforced via structured schema outputs.
  • 3D CSS Flip Card UX: Cards render with hardware-accelerated preserve-3d and rotateY(180deg) CSS transitions, allowing students to test themselves without peeking.
  • On-Demand Mode: In addition to uploaded materials, learners can enter any topic (e.g., "Quantum Computing Basics") to generate custom flashcard decks from scratch.

4. Dynamic Assessment & Quiz Engine

To verify true conceptual retention rather than superficial familiarity, the /api/quiz route generates four-option multiple-choice evaluations:

  • Distractor Plausibility: Distractor options are formulated based on common misconceptions rather than obviously incorrect answers.
  • Immediate Explanations: After selecting an option, the UI highlights the correct choice, provides a detailed rationale, and links back to the source text chunk.
  • Score Analytics: Calculates accuracy percentages and highlights specific topics that require revision.
